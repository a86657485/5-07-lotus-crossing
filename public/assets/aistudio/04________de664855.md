## 2. 风格定位与技术路线

### 2.1 画风

| 项 | 规格 |
| --- | --- |
| 风格 | **写实偏卡通**（清晰插画／轻 3D 卡通皆可，须统一一课）；**不要**突然切像素，除非整课 Godot 像素包另议 |
| 视角 | 主地图 **3/4 俯视或略抬的街景透视**；流程图／考核图用 **正面清晰线框图**（教学可读优先） |
| 分辨率 | 场景关键帧按 **1280×720** 设计；投影后排可读 |
| 模块化 | 灯柱、斑马线砖、马甲、调度屏、保温壶、法宝碎片 **可单独切图复用**；禁整屏烘焙不可改文案的大图当唯一 UI |
| 避坑 | 禁混元高面数大地图；Blender 慎高精模；优先 Godot 4 光照／简单粒子（灯闪、拥堵缓解） |

### 2.2 色板 Token（建议写入 `tokens-g5l7.css` 后续）

| Token | HEX | 用途 |
| --- | --- | --- |
| `--sky` | `#7EC8FF` | 日间天空／远景楼宇玻璃 |
| `--asphalt` | `#4B5563` | 路面 |
| `--zebra` | `#F8FAFC` / `#1F2937` | 斑马线条带 |
| `--curb` | `#9CA3AF` | 路缘 |
| `--signal-red` | `#EF4444` | 红灯芯（须形状＋色双重编码） |
| `--signal-amber` | `#F59E0B` | 黄灯芯 |
| `--signal-green` | `#22C55E` | 绿灯芯 |
| `--vest` | `#F97316` | 志愿者／小交警马甲橙 |
| `--vest-stripe` | `#FDE68A` | 反光条 |
| `--panel` | `rgba(15,23,42,.88)` | UI 深底面板 |
| `--panel-day` | `rgba(255,255,255,.92)` | 日间浅面板 |
| `--text` | `#0F172A` / `#F8FAFC` | 深／浅字 |
| `--accent` | `#F59E0B` | **唯一焦点**（按钮／脚下环／侧箭头） |
| `--accent-ink` | `#1F2937` | 琥珀按钮上的字 |
| `--ok` | `#22C55E` | 通关／灯亮／正确（锁定后） |
| `--dim` | `#94A3B8` | 未选／灯灭 |
| `--dispatch` | `#0EA5E9` | 调度屏高亮数据条 |

**对比度**：日间深字 on 浅板 ≥ 7:1；投影正文 ≥ **26–28px**，标题 **40–48px**；一屏主文案 ≤ **12 汉字**（导入防枯燥）。

### 2.3 字体

- UI：`"PingFang SC","Microsoft YaHei","Noto Sans SC",system-ui,sans-serif`
- 离线优先；禁止细线艺术字烧进场景图当唯一文案
- 流程图框内字 ≥ 22px（1280 宽基准）

## 4. 三站场景规格

### 4.1 总地图（Godot 主场景）

- **一图三工位**（压缩行走）：左侧人行横道引导台（S1）→ 中侧信号灯拆解台／流程图亭（S2）→ 右侧调度亭大屏（S3）；角落小休息点保温壶（S2-C 入口，不另开幻想地图）。
- 远景可点缀莲花山轮廓／深圳城市场景剪影，**不要**写成旅游导览字墙。
- 任务单／站门：琥珀胶囊「前往××台」；同一时刻只亮一个下一站。

### 4.2 S1 行人过街引导台

| 元素 | 视觉要点 |
| --- | --- |
| 场景 | 清晰斑马线＋一侧人行灯；行人剪影排队（少而可读） |
| 道具 | **斑马线哨**法宝碎片（哨＋小旗简形） |
| 面板 | 步骤卡横排：到达／观察并等待绿灯／过街／对面；干扰卡「先冲」视觉等权未选 |
| 成功 | 短回放：行人在「观察等待」处停顿闪烁，不为选路分叉动画 |

### 4.3 S2 信号循环拆解台（本课视觉核心）

| 子区 | 视觉要点 |
| --- | --- |
| **A 改写** | 残缺顺序图 → 学生补**菱形条件＋矩形反复＋回边**；回边用**粗琥珀箭头**（可脉冲），与分支双出口线条语言区分 |
| **B 对比** | **左右双图等权**：左循环（有回边）、右分支（天桥／等灯，无反复回边）；未作答**零高亮**；选中后仅脚下环／侧箭头，禁整卡黄框暗示答案 |
| **C 保温壶** | 休息点桌面：**不锈钢保温壶／热水壶**＋简易温度示意；标签槽「问什么／反复做什么／先问或先做」；禁「循环体」字样 |
| 先学卡 | 教材循环图截图位＋30–45s；右上 **×** 可关 |
| 法宝 | **回边箭头**碎片（抽象箭头徽章） |

### 4.4 S3 路口信号调度台

| 元素 | 视觉要点 |
| --- | --- |
| 调度屏 | 大平板／立柱屏：车流条、行人条、**时长数值**（大号）；故障态红闪「参数错乱」 |
| 运行反馈 | 「运行路口」后：拥堵车流简化动画（可关 ≤3s）→ 改规则后车流疏通；须**布置≠运行**两态皮肤 |
| 情景卡 | 车多／人多／恶劣天气 **三卡等权**（未选零高亮） |
| 法宝 | **时长旋钮**碎片（旋钮＋小信号灯 icon） |

## 6. 流程图与考核图规范（支撑 03）

考核大量「残图／双图／错圈图／保温壶图／空调残图」，须与站内流程图**同一图元语言**：

| 图元 | 画法 |
| --- | --- |
| 开始／结束 | 圆角跑道形，浅底深描边 |
| 处理（矩形） | 圆角矩形；动作短句 |
| 判断（菱形） | 标准菱形；内文**必须能答是／否**；禁把动作句塞进菱形（防 M3 视觉误导） |
| 回边 | 粗弧线箭头，颜色与分支直线出口区分（建议回边用 accent／品红系，分支用墨蓝） |
| 残图 | 缺回边／错圈时用虚线位或褪色槽，**不要**用黄柱占位 |
| 错圈图（C06） | 错误圈用半透明红虚线圈整段，正确应拆的一步可另用细框提示区（锁定前不对错） |
| 双图题（B08／C02） | 左右等大、等边距、标题对称；未选零高亮 |

线框可用 SVG／Godot 向量；插画底与线框分层，**文案可替换**。
