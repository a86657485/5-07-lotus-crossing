# 智慧路口精修交互 Implementation Plan

**Goal:** 在保留原六张剧情图与课堂记录的前提下，完成老师批准的精修交互：成熟流程图、Botbright式执行反馈、简短Maze式迁移。

**Architecture:** Godot 保留原剧情与地图；进入探究时通过 `flow:open` 打开网页任务层。网页使用 React Flow 与同一纯逻辑模型生成流程及场景执行轨迹，通过 `flow:result` 回到 Godot 站间剧情，过程记录直接使用既有 evidence API。

**Tech Stack:** Godot 4.7.2、React 19、TypeScript、@xyflow/react、SVG、SQLite课堂服务。

2026-11-06实测调整：Godot 4.7.2的当前Web导出在局域网普通HTTP下强制要求Secure Context。为完成原局域网课堂网址的部署，增加`WebLessonPlayView`兼容宿主：仅非安全上下文使用原六张剧情图与地图的网页宿主，复用完全相同的StationPanel、模型和证据接口；localhost/HTTPS继续使用Godot。没有绕过引擎安全检查，也不要求学生修改浏览器设置。此路径须在isSecureContext=false且randomUUID不可用的实际浏览器上下文中单独验收。

## 执行顺序与可验证结果

- [ ] 纯模型：同一学生方案在两种灯态有逐步轨迹，错误不会伪装通过；热水壶80/100先读后判断；S3理由不影响车流计算。命令：`npx tsx --test src/lesson/model.test.ts`，预期全通过。
- [ ] 网页站：React Flow真实渲染图形与连线、操作命中区足够大；运行/单步/暂停/撤回/重新运行均有可见反馈；错误后可修改。使用实际浏览器验证。
- [ ] Godot桥：网页进入站点后Godot内部旧面板不叠加；完成后保留原剧情图并进入真正下一步；取消回地图不记通过。原生版继续可运行。
- [ ] 数据链：首次错误与修改后通过分别记录，过程测试不挤占首答；断线刷新不丢待同步记录；重做撤销当前通过且保留历史、已开考不收回。命令：`node --test evidence.test.cjs`，预期全通过。
- [ ] 选做迁移：两种长度步道验证同一循环，出口清楚，不阻塞开考。通过模型与浏览器行为测试。
- [ ] 构建导出：`npm run lint`、`npm test`、`npm run build`；Godot无头导入及Web重新导出，同步网页实际目录。
- [ ] 独立验收：代码审查、教学五维评分、浏览器错误—修订—三站—考核、刷新恢复；使用虚构身份与独立数据目录。
