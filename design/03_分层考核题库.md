## 3 基础层全题（B01–B16）

> 学生可见：题干、选项／卡片／图位、操作说明。  
> **教师／服务端才有**：参考答案、解析、错因标签、goalIds。  
> 题干字数目标 ≤65 字；文案禁「循环体」、禁 S1／G1 等工程代号。

### B01｜点选一步｜G1 K1

- **题干**：你在莲花山路口帮行人过街。哪一步其实在「一直等到某事」？
- **交互**：点选一步（可高亮顺序微表四框）
- **选项**：A 到达路口　B 观察并等待绿灯　C 过马路　D 到达对面
- **参考答案**：B
- **解析**：反复的是「观察并等待」；到达／过街／对面各走一次，不是「一直等」。
- **错因**：A/C/D→M4（拆不出真正反复的一步）
- **对应**：G1、K1｜taskId 线索 `s1_order`

### B02｜单选｜G1 K1

- **题干**：路口灯色红→绿→黄→红……这主要说明什么？
- **选项**：A 灯在选两条不同的路　B 灯色在循环往复变换　C 必须先数清换几次　D 只有绿灯才算循环
- **参考答案**：B
- **解析**：红绿黄交替是循环往复；不是「选一条路」，次数也可因路口而异。
- **错因**：A→M1；C→M2；D→窄化循环
- **对应**：G1、K1

### B03｜单选｜G1

- **题干**：等绿灯时，要不要事先知道「一共等几次」才能画循环？
- **选项**：A 必须先知道次数　B 可以事先不知道，亮了就停　C 只能正好等 3 次　D 次数不定就不能画循环
- **参考答案**：B
- **解析**：循环可按条件结束；「绿灯亮」次数不定也成立（教材活动2）。
- **错因**：A/C/D→M2
- **对应**：G1

### B04｜点卡放置｜D1 K2

- **题干**：把「观察并等待」改成带回箭头的图。菱形里该放哪句？
- **交互**：点卡片→点菱形空槽（可拖）
- **卡片**：①绿灯未亮？　②原地观察红绿灯　③现在该过马路吗？　④过马路
- **参考答案**：①绿灯未亮？
- **解析**：菱形要可答是／否的条件；②是动作误入菱形；③偏「选路」意图。
- **错因**：②→M3；③→M1；④→M3/M4
- **对应**：D1、K2｜`s2_rewrite`

### B05｜点卡放置｜D1

- **题干**：条件成立时，反复做的矩形步骤是？
- **交互**：点卡片→点矩形空槽
- **卡片**：①原地观察红绿灯　②过马路　③到达对面　④到达路口
- **参考答案**：①
- **解析**：反复的是原地观察；过街与到达对面在循环结束后顺序执行。
- **错因**：②③④→M4
- **对应**：D1｜`s2_rewrite`

### B06｜点选回边｜D1 K2｜逆向

- **题干**：回边箭头应从菱形「还要再等」的一侧接到哪里？
- **交互**：紧凑框图＋四点选
- **选项**：A 接回「原地观察」　B 接到「过马路」　C 接到「开始」　D 接到「到达对面」
- **参考答案**：A
- **解析**：条件成立＝再做一遍观察；接到过街／对面会变成错误路径。
- **错因**：B/D→M3；C→回边越级
- **对应**：D1、K2｜`s2_rewrite`

### B07｜单选＋残图｜D1｜最小反例

- **题干**：图上只有：到达→观察等待→过街→对面，**没有回箭头**。能否表示「一直等到绿灯」？
- **选项**：A 能，有顺序就够　B 不能，缺「还要不要再等」的回边　C 能，写下「等待」即可　D 不能，因为少了天桥
- **参考答案**：B
- **解析**：缺回边就无法描述条件成立时再观察；天桥非本问必需。
- **错因**：A/C→M3；D→跑题（B4 干扰）
- **对应**：D1

### B08｜双图点选｜D2 G1

- **题干**：两张图都有菱形。哪张在问「还要不要再等」？
- **交互**：左＝带回边的等灯循环图；右＝「有天桥吗→上天桥／等灯」分支图。点选左或右（或点高亮回边）
- **参考答案**：左图（循环／回边）
- **解析**：循环看回边与「再做」；分支两路通常各走一次。
- **错因**：选右→M1
- **对应**：D2、G1｜`s2_vs_branch`

### B09｜单选＋框图｜D2｜排障

- **题干**：同伴把「有天桥吗→上天桥／等灯」说成循环。主要错在哪？
- **选项**：A 这是选路，常各走一次，没有「再做一遍」的回边　B 天桥不能画进图　C 分支不能有菱形　D 必须先问水温
- **参考答案**：A
- **解析**：同用菱形，控制意图不同：选路 ≠ 再做（对标教材「可与条件判断对比」）。
- **错因**：B/C→形式误；D→场景串台
- **对应**：D2｜`s2_vs_branch`

### B10｜点卡放置｜D3 K2

- **题干**：志愿者休息点保温壶图。循环条件（在问什么）是？
- **交互**：点卡片→条件槽（不问背具体℃）
- **卡片**：①水温还低于设定？　②继续加热　③打开壶盖　④到达对面
- **参考答案**：①
- **解析**：条件是可答是／否的问句；②是反复步骤，不是条件。
- **错因**：②→M3；③④→无关
- **对应**：D3、K2｜`s2_kettle`  
- **红线**：题干与卡片均不出现「循环体」

### B11｜单选＋流程图｜D3

- **题干**：保温壶图先「读水温并比较」，再决定是否加热。这是？
- **选项**：A 先问再做　B 先做再问　C 只选一条路的分支　D 只能先加热
- **参考答案**：A
- **解析**：先判断再执行＝先问再做；先加热再问够不够则是先做再问。
- **错因**：B→M5；C→M1；D→M5
- **对应**：D3｜`s2_kettle`

### B12｜单选＋错图｜K2 D1｜排障

- **题干**：有人在菱形里写「原地观察红绿灯」。这样画主要错在哪？
- **选项**：A 菱形里应是可答是／否的条件，不是动作　B 菱形必须涂成红色　C 少画了天桥　D 要把次数写进菱形
- **参考答案**：A
- **解析**：菱形起循环指示，内容须是条件；动作放矩形。
- **错因**：B/C 形式凑数已清零；若选 D→M2
- **对应**：K2、D1

### B13｜策略点选｜G2

- **题干**：调度台：该方向「车很多」。机动车绿灯时长更合理的是？
- **选项**：A 给该向机动车加长　B 只加长行人、缩短机动车到接近 0　C 随便设都一样　D 改成常红
- **参考答案**：A
- **解析**：车流量大的方向配置更长机动车通行时间（教材活动3）。
- **错因**：C→M7；B/D→不合理策略
- **对应**：G2｜`s3_timing`

### B14｜单选｜G2

- **题干**：你选「加长」的主要理由是？
- **选项**：A 让车更快疏散，小设置服务整条路口　B 因为名字叫智慧交通　C 设错了也没关系　D 只为让屏幕好看
- **参考答案**：A
- **解析**：意义在疏导与「小设置→大系统」，不是背名词。
- **错因**：B/C/D→M7
- **对应**：G2｜`s3_timing`

### B15｜策略点选｜G2

- **题干**：开放日「人很多」。更合理的时长策略是？
- **选项**：A 加长行人通行时间　B 只加长机动车绿灯　C 取消所有条件判断　D 灯时长必须全年固定
- **参考答案**：A
- **解析**：人群聚集处加长行人通行时间；时长可因人流调整。
- **错因**：B 场景错配；C→M6；D→否认调节意义（M7）
- **对应**：G2｜`s3_timing`

### B16｜三行匹配｜G1 K1

- **题干**：把现象与「反复做什么／何时停」配对（每行点选一卡）。
- **交互**：匹配表

| 现象 | 可选卡（每行三选一） |
| --- | --- |
| 等绿灯过街 | 原地观察／绿灯亮停｜过马路／到对面停｜数满 3 次就停 |
| 保温壶加热 | 继续加热／达设定停｜只加热一次｜打开盖子作条件 |
| 红绿黄交替 | 按序换灯色／一轮后再来｜只亮一次绿灯｜选上天桥 |

- **参考答案**：行1＝原地观察／绿灯亮停；行2＝继续加热／达设定停；行3＝按序换灯色／一轮后再来
- **解析**：三例都有「反复步骤＋停止条件」；次数不必预先固定。
- **错因**：选「数满 3 次」→M2；选「过马路／到对面」→M4；选天桥→M1／跑题
- **对应**：G1、K1

### C01｜单选＋回放｜D1｜排障

- **题干**：回边被接到「过马路」。回放：绿灯未亮人却走上斑马线。错在哪？
- **选项**：A 回边应接回「原地观察」　B 菱形颜色不对　C 少了天桥框　D 「到达对面」也要放进反复框
- **参考答案**：A
- **解析**：回边接错会导致未亮灯就进入过街；应接回反复观察。
- **错因**：D→M4；B/C→无关
- **对应**：D1

### C02｜双图点选｜D3

- **题干**：图甲：先比水温再加热。图乙：先加热再问够不够。图甲是？
- **选项**：A 先问再做　B 先做再问　C 分支选路　D 必须预先知道次数
- **参考答案**：A
- **解析**：甲先判断后执行；乙先执行后判断；均不引入术语名。
- **错因**：B→M5（看反）；C→M1；D→M2
- **对应**：D3｜`s2_kettle`

### C03｜策略点选｜G2

- **题干**：暴雨天视线差。信号时长更合理的是？
- **选项**：A 预留更长反应／通行时间　B 全部改闪烁、不管车流　C 取消行人灯　D 时长与天气无关
- **参考答案**：A
- **解析**：可按天气预测预留更长通行／反应时间（教材活动3）。
- **错因**：D→M7；B/C→危险或无效策略
- **对应**：G2｜`s3_timing`

### C04｜单选＋空调残图｜G2 D3｜反例（B18）

- **题干**：休息室空调图若去掉「室温＞预期」一侧的回边，还能一直自动调温吗？
- **选项**：A 不能，缺少反复判断与回边　B 能，读一次温度就够　C 能，制冷会自己永远转　D 不能，因为少写了「开始」
- **参考答案**：A
- **解析**：自动调温靠条件＋回边反复读温／制冷；缺回边则无法持续调控。
- **错因**：B/C→否认循环；D→抓错缺失点
- **对应**：G2、D3｜选做迁移 B18  
- **红线**：不出现「循环体」

### C05｜积木拼接｜D1 K2｜编程猫 Kitten

- **题干**：用积木表示「重复观察，直到绿灯亮」。`重复执行直到` 的条件格应放？
- **平台**：编程猫 Kitten（控制／事件官方叫法）
- **固定积木**：`当开始被点击` → `重复执行直到〈　〉` → 内层示意「观察红绿灯」
- **可点积木卡**：①绿灯亮起　②绿灯未亮　③过马路　④重复执行 (10) 次　⑤如果〈　〉否则
- **参考答案**：条件格＝①绿灯亮起（与固定「重复执行直到」搭配）
- **解析**：Kitten「重复执行直到〈条件〉」在条件为真时结束；直到「绿灯亮起」才停，内层反复观察。④预先固定次数不符「次数可不定」；⑤是分支。
- **错因**：②→条件方向反（M3／意图反）；④→M2；⑤→M1
- **对应**：D1、K2  
- **核实备注**：控制类「重复执行直到」／事件类「当开始被点击」按编程猫源码图鉴叫法；**先按现文案用**，有校机截图后再微调颜色／文案（老师 2026-11-01 确认）。

### C06｜单选＋错圈图｜D1｜最小改法

- **题干**：有人把「到达→等待→过街→对面」整段都圈成循环。最小改法是？
- **选项**：A 只把「观察等待」拆成带回边的反复，过街与对面留在循环外　B 全部删掉只留菱形　C 改成天桥分支　D 把次数写成 100
- **参考答案**：A
- **解析**：只拆真正反复的一步；整段圈入是 M4。
- **错因**：B 过度删除；C→M1；D→M2
- **对应**：D1｜`s2_rewrite`
