## 3. 开场导入（约 2′｜可跳过／重播｜二刷可随时关）

### 3.1 叙事节拍（每句≤25字）

1. **接到委托**：路口志愿者「阿莲」递出临时小交警马甲——「开放日人多，需要助手。」
2. **小尝试**：屏幕上行人说「等到绿灯就行」；点选：哪一步其实在「一直等」？
3. **看见困难**：系统回放卡住——「等到什么时候停？说不清。」灯时长屏闪红「参数错乱」。
4. **产生探究问题**（屏幕短句，不露编号）：「哪一步在反复？做到什么时候停？灯时长为啥要改？」
5. **进站**：任务单亮起 S1→S2→S3；焦点落在「前往行人过街引导台」。

### 3.2 交互规格

| 项 | 规格 |
| --- | --- |
| E0 | 点选「反复等」那一步；只唤醒，**不判达标** |
| 跳过 | 右上 ×／Esc／「跳过剧情」→ 直接进 S1；不记学习达成 |
| 重播 | 任务单「重看委托」可重播；二刷默认关对白，可随时关 |

## 4. S1 行人过街引导台（约 4′｜活动1 顺序铺垫）

2. **与我关系**：帮阿莲把过街步骤排对。
3. **能验证什么**：顺序图对了，就能看出哪步在「一直等」。

### 4.3 面板任务（唯一焦点｜⌫ 撤回）

| 步 | 任务提示（面板上方一行） | 操作 |

## 5. S2 信号循环拆解台（约 10′｜活动2；承载 E1+E2+E3）

> **本课有效探究主体。** 同站三段：A 改写 → B 对比 → C 保温壶。先学卡一次入口；禁「循环体」。

### 5.1 进站三问（①出事→②与我关系→③能验证什么）

1. **出事**：信号屏循环图说不清「再等」停在哪。
2. **与我关系**：帮阿莲拆灯态，分清再等还是选路。
3. **能验证什么**：回边画对、对比分清、壶先问对。

> 原三句探究题干分别下沉为 S2-A／B／C 面板任务口吻提示。

### 5.2 先学卡（30–45 秒｜必做入口）

| 项 | 内容 |
| --- | --- |
| 教材截图位 | 活动2 循环流程图（菱形「绿灯未亮？」＋回边＋「原地观察红绿灯」） |
| 微讲要点（白话） | ①菱形在问「还要不要再做」；②回边＝条件成立就再走一遍；③次数可以事先不知道 |
| 禁止 | 「循环体」一词；长定义墙 |
| 结束 | 「开始拆解」→ 焦点落到 S2-A 第一空槽 |

### 5.3 S2-A｜改写循环图（E1／D1）

**任务提示**：「把『观察并等待』改成带回箭头的图。」

**面板**：

- 给出 S1 顺出来的残图：到达路口 →［观察并等待绿灯］→ 过马路 → 到达对面。
- 学生拖拽／点选填槽：
  - 菱形条件：「绿灯未亮？」／干扰「现在该过马路吗？」（意图偏分支）／「原地观察」（动作误入菱形＝M3）
  - 矩形反复：「原地观察红绿灯」／干扰「过马路」「到达对面」（整段误圈＝M4）
  - **回边**：从菱形「是／否」正确一侧接回反复矩形；干扰：回边反接、接到「过马路」
- 锁定前**不显示对错**；锁定后短回放：条件成立→再亮「原地观察」；绿灯亮→走出循环去「过马路」。
- **首次锁定**记 E1 首答；⌫ 可改，改后需重锁。

**通关**：条件框可答是／否＋反复步骤正确＋回边方向合法（与教材同构；等价反问写法若卡片提供则按等价接受，本站默认教材向）。

### 5.4 S2-B｜循环≠分支（E2／D2）

**任务提示**：「两张图都有菱形。哪张在问『还要不要再做』？」

**面板**：

- 左：S2-A 学生刚锁的循环图（或标准循环对照图），强调**回边**。
- 右：分支图——「有可用天桥吗？／是→走天桥／否→等灯过」（各走一次，无回边反复）。
- 操作：点选「在决定要不要再等／再做」的那张，或点高亮回边区域。
- 防混：两图皆有菱形，迫使学生比**控制意图**（M1）。

**通关**：选对循环意图图／正确指出回边。一句收束（≤25字）：「选路各走一次；循环是再做一遍。」

### 5.5 S2-C｜保温壶「先问再做」（E3／D3）

**情境落点**：路口志愿者休息点的**保温壶／热水壶**（真实职责旁白，不另开地图幻想）。

**任务提示**：「标出：问什么、反复做什么、先问还是先做。」

**面板**（对齐教材热水壶流程图结构）：

- 点选标签槽：
  - 循环条件：「水温低于设定？」类（不问背具体℃数字）
  - 反复步骤：「继续加热／再检测」
  - 判断时机：「先问再做」或「先做再问」（本图以教材「先读温再比再加热」为先问再做样例；可附一张「先加热再问够不够」对照轻点）
- 文案全程：**循环条件／反复步骤／先问／先做**；**禁止「循环体」**。

**通关**：三处标签正确（结构对即可，不考背数）。

## 6. S3 路口信号调度台（约 3′｜活动3；承载 E4）

### 6.1 进站三问（①出事→②与我关系→③能验证什么）

1. **出事**：路口堵了，时长好像设错了。
2. **与我关系**：帮阿莲调信号时长，让路口更顺。
3. **能验证什么**：换规则后再运行，看拥堵有没有缓解。

> 原探究问句下沉为 §6.3 各阶段面板任务提示。

### 6.2 先学卡（≤20s｜内嵌，勿科普长文）

- 教材截图位：活动3「预设红绿灯时长」示意图（采集→数据→配置）。
- 微讲一句：「小设置调对了，整条路口更顺——这就是智慧交通。」（B16，任务口吻）

### 6.3 核心机制：布置 vs 运行分离＋先实测故障再换规则

| 阶段 | 学生做什么 | 设计意图 |
| --- | --- | --- |
| **① 实测故障（反例）** | 调度屏预置错误时长（如：车很多的方向绿灯极短）；点「运行路口」→ 可见拥堵／行人空等 | 先看见「设错了会堵」，再改；对齐「布置≠运行」 |
| **② 布置规则** | 情景卡三选一环境：**车多**／**人多**／**恶劣天气**；点选更合理的时长策略（如：车多→该向机动车绿灯加长；人多→行人通行加长；恶劣天气→预留更长反应／通行时间等预制项） | E4 策略点选；零打字 |
| **③ 选理由** | 预制理由点选（对应 M7：禁止只背「智慧交通」空词）例：「让车／人更快疏散」「小设置服务整条路口」／干扰「因为名字叫智慧」「随便设都一样」 | 意义侧 G2／SC6 |
| **④ 重验** | 再点「运行路口」→ 拥堵缓解动画（可关，≤3s） | 改规则后必须重验；历史故障回放可查 |

**任务提示（面板上方一行）**：随阶段切换，如「先运行，看现在哪里堵」→「按车多／人多选时长」→「选出你的理由」→「再运行一次核对」。

### 6.4 通关标准与出口

- 通关：完成故障实测＋至少一张情景卡的策略与理由正确＋重验通过。
- 出口：阿莲：「时长设对了，路口顺多了。」收「时长旋钮」碎片；三站勾完 → **自动开考（E5）**。
- 服务：G2；暴露 M7。课后观察路口**不计入**当课必做（B17）。

### 7.4 解锁核验态分支（常驻｜锁态按状态分支）

凡解锁依赖「前置已做／已核验」时，**UI／对白／焦点／通关法宝文案必须按当前进度状态分支**，禁止写死单一话术。

#### 三态定义（全站通用）

| 状态码 | 含义 | 焦点／对白／法宝口径 |
| --- | --- | --- |
| `pre_missing` | **未做前置** | 指路去真正缺的前置站／子任务；法宝只高亮「去哪一站」，不代做 |
| `pre_done_unverified` | **已做前置、尚未核验／未提交锁定** | **禁止**再指「重做该前置」；改为「点锁定／提交核验／打开下一面板」 |
| `verified_ready` | **已核验，待进下一站／已解锁** | 焦点落到下一站入口；法宝可提示「前往下一台」 |

#### S3 专例（防再指「重跑故障」）

| S3 子进度 | 状态 | **禁止** | **应指引** |
| --- | --- | --- | --- |
| 未点「运行路口」实测 | `pre_missing` | — | 「先运行，看哪里堵」 |
| **已跑出拥堵／反例，尚未换规则或未重验** | `pre_done_unverified` | **禁止**法宝／焦点再说「再跑一遍故障／用原时长重现」 | 「按车多／人多选时长」→「选理由」→「再运行核对」 |
| 已换规则且重验通过 | `verified_ready` | — | 收碎片／开考提示 |

#### 自救入口（建议）

学生端每站提供 **「重做本关」**：清本关进度或按设计重置本关 `taskId` 状态；**不强制扣分**；不清整课法宝已用次数以外的他站证据（除非整课重开 `runId`）。

## 8. 引导与焦点规范

1. **同一时刻只高亮唯一下一步**（下一空槽／唯一按钮／唯一可点 NPC）；从不高亮整表或多卡同时抢焦。
2. **对白单句≤25字**；可 ×／Esc／跳过；跳过只推叙事 flag，不设学习达成。
3. **操作面板上方一行任务提示**（随子任务切换；勿多段说明墙）。
4. 浮层打开时隐藏地图光圈；关闭后重算当前焦点。
5. 停顿加强（idle）：只讲操作（「先点卡片再点空槽」），不泄概念答案。
6. 二刷：剧情／引导弹窗可**随时关**；关闭后恢复当前操作与进度，不能以关闭代替完成任务。
7. 拖放与点选双支持；拖放成功后下一次单击不得被吞。
8. 给学生成功标准可用 SC1–SC6 短句（见 01 §2.4）；**严禁**在学生 UI 出现 G/K/D/E/M 编号。

## 11. 自检三段

### ① 机制如何嵌目标

- 玩的就是：**回边＝再等一遍**（E1/D1）、**菱形意图≠选路**（E2/D2）、**先问／先做点选**（E3/D3）、**时长布置后运行见效**（E4/G2）。
- 积分／行走／对白次数**不**单独证明理解；独立证据靠面板首答与考核。

### ② 何处避免照搬教材原文情景仍对齐

- 身份换成「莲花山临时小交警助手」，冲突是「说不清停＋时长调乱」，不是课堂念五步课文。
- 热水壶落到「志愿者休息点保温壶」，结构对齐教材、外壳生活化。
- 天桥一句带过、不设支线；E4 直接用路口信号时长（老师拍板），不另编岛／工坊隐喻。
- 与第6课零重叠：职责是路口引导／拆解／调度，不是园区巡检选路。

### ③ 为什么五年级学生想跟进

- 真实深圳地标＋「当小交警」身份感；怕路口堵／灯乱的紧迫感自然咬合探究问题。
- 每站进站三问任务口吻；短回放看见「再等／停下／变顺」；法宝三碎片收集闭环。
- 操作零打字、可撤回、焦点单一，弱生不因界面负担掉队。
