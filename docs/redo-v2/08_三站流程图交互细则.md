## 1. 全课通用：教材式图元与操作

### 1.1 视觉（对齐 `教材_算法流程图参考.jpg`）

| 图元 | 形状／色 | 用途 |
| --- | --- | --- |
| 起／止 | **绿色**圆角矩形（stadium） | 到达…／结束… |
| 处理 | **浅蓝**圆角矩形 | 反复或一次动作步骤 |
| 判断 | **深蓝**菱形 | 可答「是／否」的条件句 |
| 前进箭头 | 蓝竖／折线箭头 | 「否」出口前进到下一处理 |
| 回边 | 自菱形「是」弯回上方处理框（橙或教材蓝，**一眼看出「再做一遍」**） | 条件成立→重复 |

竖排为主；出口旁标「是」「否」；投影字号可读。

### 1.2 操作硬约束

1. 只 **单击／拖拽**＋**`⌫` 撤回**（撤回不扣分；E1 改后需**重锁**）。
2. 同一时刻 **唯一焦点**（FocusRing）。
3. 锁定前可随意改；**锁定后**才跑世界回放／判通关。
4. 通关法宝整课 **3**（指路＋讲为什么，**不代做**）。
5. 三错递进：观察→思路→具体帮助，**不直接给本题答案**。
6. 对白／先学／流程图面板打开时：**禁止走动**，完成或关闭后再走。
7. 学生端文案禁 G/K/D/E/M 编号；禁「循环体」。

### 1.3 每站节拍

先学卡（教材截图位＋30–45s 或更短）→ 进站三问对白（带 CG）→ **流程图探究** → 短收束对白（带 CG）→ 收碎片／解锁。

### 2.2 画布初始态

**已放置（固定，不可删）**

```
[绿起] 到达十字路口
        ↓（已连）
[蓝处理] 原地观察红绿灯
        ⋮  ← 此处空缺：菱形槽＋出边
[蓝处理] 过马路          ← 与上方暂断开或仅虚线暗示「缺判断」

[绿止] 到达马路对面
```

| 状态 | 说明 |
| --- | --- |
| 已放 | 绿起「到达十字路口」；蓝处理「原地观察红绿灯」；蓝处理「过马路」；绿止「到达马路对面」；起→观察、过马路→止 的竖箭 |

> 与教材参考图同构：是→回边再观察；否→过马路→对面。

### 2.3 卡片池文案

**底栏／侧栏卡片（点选或拖入菱形槽；矩形仅当干扰误入菱形时用）**

| cardId | 形状意图 | 文案 | 正／扰 | 防误解 |
| --- | --- | --- | --- | --- |
| `cond_green_off` | 菱形 | **绿灯未亮起？** | **正确** | — |
| `cond_bridge` | 菱形 | 有可用天桥？ | 扰（分支意图） | M1 |

回边／否边：**不**做成「空位按钮」，而是菱形两出口上的拉线柄：点「是」→点目标处理框；点「否」→点「过马路」。

### 2.4 连线规则

| 边 | 合法接法 | 错接判定 |
| --- | --- | --- |
| 入边 | 「原地观察红绿灯」→ 菱形「绿灯未亮起？」 | 跳过菱形直连「过马路」＝未完成 |
| **是** | 菱形「是」→ **回接到「原地观察红绿灯」**（弯回上方；允许接到观察框顶边或观察←起之间竖线） | 「是」接到「过马路」／「到达对面」／起框＝错回边；回放卡住或行人误冲 |
| **否** | 菱形「否」→ **「过马路」** | 「否」回接到观察＝反接；「否」接到起框＝错 |

锁定前不对错；非法边可拉但不记通关，世界回放暴露后果。

### 2.5 对错可见后果（莲花山世界）

| 状态 | 世界事件 |
| --- | --- |
| 菱形错／回边错／未锁 | 行人挤、有人迈步乱穿；灯柱观察闪烁异常停住或行人提前冲出斑马线 |
| 合法锁定后回放 | 条件成立（未亮）→ 灯柱／行人再播一轮「抬头观察」；条件不再成立（亮了）→ 走出循环，行人有序过马路 → 到达对面 |
| 通关 CG | `cg_s1_flow_ok`：队伍整齐、灯偏绿 |

阿莲错序句：「看，有人挤出斑马线了。」未完成：「还没把『再等』画清楚。」

### 2.6 三错支架（不给本题答案）

| 层 | 文案 |
| --- | --- |
| L1 观察 | 「看看行人卡在哪；菱形里要能答是或否。」 |
| L2 思路 | 「『是』的箭头该指回还在做的那步吗？到达对面还要再做吗？」 |
| L3 具体 | 换地名的同结构示意图（如「校门口灯」）标出菱形与弯回，**不圈本题槽内文案** |

法宝：高亮菱形空槽＋白话「把一直等改成：问还要不要再观察。」不代拉回边。

### 2.7 通关判据与 ⌫

**通关（E1）**：`conditionCardId=cond_green_off` ∧ 反复框＝「原地观察红绿灯」∧「是」回边合法接到该反复框 ∧「否」接到「过马路」∧ 起止完整。教材同构即可。

- ⌫：撤上一张入槽卡或上一笔连线；不扣分；若已锁定则解锁并需重锁才记新 attempt。
- 附属过程（可选）：点选高亮「原地观察红绿灯」为「一直等」那步 → 可写入 `s1_order` 过程包；**不得**出现空位1–5排序 UI。

### 2.8 与 E1–E4 对应

| 证据 | 本站 |
| --- | --- |
| **E1** | 主：首次锁定正确＝首答；法宝／三错后锁定＝支持后 |
| E2–E4 | 本站不采集 |

| 绿起「开始保温」；绿止「可以倒水」；蓝处理「停止加热」；止前竖箭 | ① 蓝处理 **「检测水温」**（反复相关）② 蓝菱 **「水温是否低于设定？」**（不问背具体℃）③ 蓝处理 **「继续加热」** ④ 「是」回边接到「继续加热」或「检测水温」（与所选时机一致）⑤ 「否」接到「停止加热」⑥ **时机标签**：先问再做／先做再问 |

| cardId | 形状 | 文案 | 正／扰 |

#### 连线规则

| 边 | 先问再做（默认合法） | 错接 |
| --- | --- | --- |
| 主链 | 起→检测→菱形；否→停止→止 | 起直接→停止 |
| **是** | 菱形是→**继续加热**→回**检测水温**（或是→回检测且加热在回边路径上） | 是→止；是→起 |
| **否** | →停止加热 | 否→继续加热且无停止 |

时机标签须与拓扑一致：标「先问再做」则菱形前必须先有「检测」；标「先做再问」则菱形前先有「加热」。

#### 对错可见后果

| 对 | 壶体短循环：加热→检测→再加热…直到条件停；蒸汽／液面动画停在「可以倒水」 |
| 错 | 壶空转、一直加热不判停、或瞬间跳停；⌫ 重贴 |

#### 三错支架

| 层 | 文案 |
| --- | --- |
| L1 | 「图上先出现问句还是加热？菱形里能否答是或否？」 |

| L3 | 两张换情景小图（空调冷气）并排点「先问／先做」，不引入术语 |

#### 通关与 ⌫

- 通关：`conditionId=k_cond` ∧ `repeatStepId∈{k_repeat_heat,k_repeat_check}` 结构正确 ∧ `timingChoice` 与拓扑一致 ∧ 是／否边合法。
- ⌫：撤卡／撤边；改后重锁；文案只用「循环条件／反复步骤／先问／先做」。

### 4.4 连线规则

- 本站**不以拉回边判对错**；只读循环示意不可改边。
- 「布置」只改策略／理由面板，**路口不自动变**。
- 必须：**先运行故障**（`faultObserved=true`）→ 布置 → **再运行**（`revalidateOk`）。
- 未跑故障＝`pre_missing`；已实测未换规则＝`pre_done_unverified`；重验通过＝`verified_ready`。
- 法宝在 `pre_done_unverified` **禁**再指「重跑故障」。

### 4.5 对错可见后果

| 阶段 | 世界 |
| --- | --- |
| ① 运行预置故障 | 车流条堵死／行人空等；时长屏可闪红 |
| ②③ 只布置 | 面板数字变，路口暂不变 |
| ④ 策略＋理由对且再运行 | 拥堵缓解动画 ≤3s（可关） |
| 错策略再运行 | 仍堵或另一向更堵；可 ⌫ 改策略后重跑 |

### 4.6 三错支架

| 层 | 文案 |
| --- | --- |
| L1 | 「先运行，看哪边堵。」／「别再空跑故障，先换时长。」 |
| L2 | 「车多的那边，绿灯是不是太短？」 |
| L3 | 「想想：改哪一边能让积压的车先走完？理由要说清『路口更顺』。」（不代点选项） |

### 4.7 通关与 ⌫

- 通关：故障实测 ∧ 策略与理由正确 ∧ 重验通过。
- ⌫：撤策略／理由卡；不回补法宝；改后需再运行才更新 `revalidateOk`。
- 出口：阿莲「时长设对了，路口顺多了。」收「时长旋钮」；三站齐 → `exam:open`。CG：`cg_exam_ready`。
